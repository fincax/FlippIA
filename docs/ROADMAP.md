2. Conector oficial Urbanismo Sevilla / IDE Sevilla WFS; Catastro público validado en producción.

4. Documentos: storage S3 con signed URLs, antivirus, OCR de nota simple/planos → evidencia.
5. Workers durables (colas) para análisis largos y Smart Watcher programado.
6. Execution mode (proyecto, presupuesto, certificaciones, desviaciones), Learning Engine y Deal Memory.
7. Partner/Architect Network con attribution; FlippIA Funding con brokers reales.
8. Mapa con tiles (`map.tiles`), Lens (`lens.beta`), inglés (i18n), nuevas ciudades (CityProfile).
9. Negotiation Intelligence (argumentario), exportación PDF servidor.
